# caliper_control_system

⚙️ Advanced Control System Design for Paper Caliper Optimization
This project involved the design and implementation of an advanced control system to optimize paper caliper in the manufacturing process. The solution leveraged real-time communication with the QCS (Quality Control System) and a Python-based server to receive and analyze caliper profile data from a scanning measurement frame.

The system processed these profiles and generated a second-order polynomial to evaluate the concavity of the caliper profile. Based on this analysis, it automatically adjusted the pressure of the calender rolls, ensuring more uniform thickness across the paper sheet.

This closed-loop control solution led to significant improvements in product quality, a notable reduction in production rejects, and increased process efficiency through waste minimization.

🎯 General Objective
Design and implement an automated control system to improve paper caliper uniformity using real-time profile analysis and dynamic pressure adjustment, enhancing product quality and reducing production waste.

🔧 Technologies Used:

Python (data processing, server development)
Real-time communication protocols with QCS
Statistical modeling (second-order polynomial fitting)
Industrial automation systems (actuation and pressure control)

🎯 Impact:

Enhanced paper caliper uniformity
Improved final product quality
Reduction in production rejects and material waste
Increased manufacturing process efficiency
